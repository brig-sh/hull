## Highlights: Claude Desktop, sandboxed

We could already run the Claude Code CLI inside a urunc microVM on macOS. This
release brings the full **Claude Desktop app** -- the GUI, not just the CLI --
into the same sandbox, rendered as a native window on your Mac.

The app runs on a Linux guest under Apple's Virtualization.framework. Its
window is a real macOS window (mouse, keyboard, resize all work), but
everything it does stays inside the VM. Sign-in works too: "Continue with
Google" opens a browser inside the guest and hands the session back to the
app, so your credentials never leave the sandbox.

What's new:

- `hull --gui` -- run any instance with a windowed display
  (virtio-gpu via Virtualization.framework).
- `urunc-claude-desktop` -- a Homebrew wrapper that boots the Claude Desktop
  image with a persistent home under `~/sandboxed-claude-desktop`.
- A guest image (`urunc-claude-desktop`) with the app, a Wayland kiosk, and an
  in-guest browser for OAuth.
- A from-source arm64 guest kernel with virtio-gpu and virtio-fs built in, so
  graphics and the persistent home work with no module loading.

A couple of honest notes. Rendering is software (no 3D acceleration for Linux
guests under AVF), which is fine for the app itself. The first-run login is
manual, as it should be -- we drive the flow up to the Google prompt, you
enter your own credentials.
