# Architecture Decision Records

| ADR | Title | Status | Summary |
|---|---|---|---|
| [0001](0001-single-nic-usermode-gateway.md) | Single-NIC user-mode network gateway for compose networking | Accepted | Each compose service gets one NIC on a gvisor-netstack gateway (switching, NAT egress, DNS, ports), keeping the guest contract identical to urunc on Linux |
| [0002](0002-compose-conformance-suite.md) | Compose-spec conformance suite with percentage scoring | Accepted | Manifest-driven black-box suite scoring compose-spec coverage; every capability claim backed by a test, unsupported keys fail loudly, supported ones document security tradeoffs |
| [0003](0003-compose-out-of-scope.md) | Declare permanently out-of-scope compose capabilities | Accepted | 21 structurally-foreclosed capabilities (orchestration, cross-VM namespace sharing, Windows-only, Docker-platform machinery, device passthrough) get an out-of-scope status; headline score re-bases to in-scope, full-spec coverage stays printed, every excluded key still warns loudly |
| [0004](0004-exec-support-branch.md) | exec-support experiment branch to measure exec-driven conformance gain | Accepted | Long-lived exec-support branch pins the urunc fork's feat/exec-runc-delegate and builds the missing compose exec layer (compose exec, exec healthchecks, hooks); the conformance suite measures the before/after delta; main stays clean of the experimental pin |
| [0005](0005-compose-interpolation-env-file.md) | Variable interpolation and env_file for compose | Accepted | Raw-text interpolation (all substitution forms, .env + --env-file, docker precedence) and the env_file service key, so real compose files load; both static-tier testable on main |
| [0006](0006-compose-named-volumes.md) | Named volumes for compose | Accepted | Store-managed host directories (docker's project_name naming) over the existing virtiofs plumbing; declaration required, down --volumes deletes, multi-writer coherence divergence documented |
| [0007](0007-compose-exit-status-oneshot-restart.md) | Exit status, one-shot services, and restart policies | Accepted | One-shot services run through the guest agent for an exact exit code (gating service_completed_successfully), InstanceState records it, and the gateway daemon supervises restart policies; upstream urunc#336's urunit work is sequenced follow-up, not a blocker |
| [0008](0008-telemetry.md) | First-party usage and crash telemetry | Accepted | Opt-out anonymous usage events and crash reports for hull/urunc-claude/urunc-claude-desktop, sent to a first-party endpoint; notice before the first event, random local UUID at most, `DO_NOT_TRACK` honored, full schema documented in docs/telemetry.md |
| [0009](0009-adopt-compose-go-loader.md) | Adopt compose-go as the compose loader | Accepted | Replaces the ~3,400-line hand-rolled parser with compose-go v2.14.0 behind a new internal/compose package, consuming its types.Project directly; docker behavior wins on all divergences, gated by ADR-0002's conformance suite staying monotonic and at or above 15.4% |
